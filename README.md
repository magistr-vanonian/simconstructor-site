# Промо-сайт конструктора симуляций

Отдельный репозиторий: Node.js (Express) + React (Vite). Палитра — чёрный, коричневый, золотой.

Разделы: **Главная** (пустая), **Ресурсы**, **Инструкция**.

Облачный сервер и домен подключаются следующим шагом. Сейчас хранилище — локальная папка `storage/` (тот же контракт API, что потом уйдёт в облако).

## Запуск

```bat
cd simconstructor-site
npm run install:all
npm run dev
```

- API: http://127.0.0.1:8787
- Сайт: http://127.0.0.1:5173

Прод: `npm run build` затем `npm start` (раздаёт `client/dist` с того же порта 8787).

## Инструкция

Шаблон: `content/instructions.json`.

Видео кладите в отдельные подпапки:

- `content/videos/01/`
- `content/videos/02/`
- …
- `content/videos/06/`

Подходят `mp4` / `webm` / `ogg` / `mov`. Если файла нет, страница показывает заглушку и не падает.

## Ресурсы

Кнопка «Скачать конструктор» отдаёт `storage/constructor/SimConstructor-Release.zip`.

Ниже — библиотека: сцены, скомпилированные симуляции, ландшафты (с атласами), фигурки, шрифты, текстуры. Список читается из `storage/library/`. Сцены загружаются папкой (`.gem` вместе с мешами, шрифтами и картинками в тех же именах каталогов, что в редакторе) и всегда с эмблемой конструктора. У остальных миниатюра — картинка из загрузки, иначе та же эмблема.

Загрузка на полку с диска — без учётки (демо).

## Как собрать и выложить релиз конструктора

Из корня Kristal_Engine:

```bat
publish-simconstructor-release.cmd
```

Скрипт:

1. Берёт `SimConstructor/build/Release`
2. Собирает чистую папку `SimConstructor-Release` (без импортированных карт, фигурок, шрифтов, ландшафтов, симуляций, `.sources`)
3. Пакует zip
4. Кладёт архив в `simconstructor-site/storage/constructor/` и сообщает API, если сайт запущен

Нужен уже собранный Release. Пересобрать редактор: `publish-simconstructor-release.cmd -Build`

Токен публикации (чтобы с сайта нельзя было перезатереть конструктор): `PUBLISH_TOKEN`, по умолчанию `kristal-demo-publish`.
